# Exceptions for tools/check-content.sh. One per line:
#
#   <check> <path-glob> <word|*>  # reason (required)
#
# <check> is ext, magic, size, lfs, mark or autoname. <path-glob> is matched against the
# repository-relative path with fnmatch ("*" also matches "/"). <word> is the matched
# trademark word or decompiler name, or "*" for any. Keep this list short: every entry
# is a reviewed decision, and a reviewer should be able to agree with the reason alone.

# The plugin API's native package is called `Turbine` (`Turbine.UI`, `Turbine.Gameplay`,
# `Turbine.UI.Lotro`); existing third-party plugins call it by that name. LEGAL.md §17.2
# rule 1: the names enter the code as string data in the plugin subsystem only, and the
# plugin subsystem's tests may also use them (test names, local bindings). Source modules,
# types and the plugin-free core `crates/script` stay neutral (decision 0023).
mark crates/plugins/tests/* turbine  # LEGAL §17.2 rule 1: plugin subsystem tests may use the API names
mark crates/plugins/tests/* lotro  # LEGAL §17.2 rule 1: plugin subsystem tests may use the API names

# The UI fallback font, Noto Sans Regular (SIL OFL 1.1), bundled unmodified by owner
# decision 0022 and recorded in LEGAL.md §11. Exactly this one path; game fonts are never
